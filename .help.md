# Welcome to Arch Linux!

This file contains helpful tips, commands, recommended software, and recommendations for further resources if needed.

## Terminal Basics

First and foremost - double and triple check your spelling and syntax when using the terminal. Careless mistakes can turn happy into headache, or even nightmare.

- Use `Tab` to autocomplete commands and file names
- Press the `Up Arrow` to cycle through previous commands
- Use `CTRL+R` to reverse-search your command history
- `CTRL+C` or `q` are often used to quit interactive prompts or ongoing tasks
- `CTRL+SHFT+C` or `CTRL+SHFT+V` are often used for copy and paste functions

## Common Commands

- `sudo` - 'super user do'. This command executes other commands with admin privileges.

Package Management - installing, removing, and updating software
- `pacman` - the Arch Linux package manager
- `sudo pacman -Syu` - updates the whole system (run once per week. Wednesdays or Thursdays are best)
- `sudo pacman -S PACKAGE-NAME` - installs a specified package
- `sudo pacman -Rns PACKAGE-NAME` - removes a specified package, and its unique dependencies

For ease (enabled by the provided .bashrc file)
- `arch-update` - updates the whole system
- `arch-install PACKAGE-NAME` - installs a specified package
- `arch-remove PACKAGE-NAME` - removes a specified package, and its unique dependencies

Navigating files and directories (folders)
- `ls` - lists files and sub-directories within your current directory
- `cd FOLDER` - 'changes directory' to specified folder
- `cd ..` - moves 'up' the directory tree by one
- `cd` - moves you to your home directory if nothing else is specified

Locations
- `~/` - the current user's home directory
- `/` - the root directory

Other common commands
- `cat` - displays text from specified file within the terminal
- `ping google.com` - pings google to test for internet connection
- `lsblk` - lists drives, partitions, and mount points
- `lsblk -f` - lists file system types of partitions
- `systemCTRL` - manages 'hands free' services such as starting your login screen, firewall, or bluetooth manager while booting up

Help with Commands
- `COMMAND -h` or `COMMAND --help` can commonly be used to get immediate assistance using a command
- Commands have 'man pages' (manuals) which can be viewed from the terminal or are available online

## Other Useful Commands

Unzip tar files
- `tar -xzvf FILENAME.tar.gz -C /DIRECTORY` - for tar.gz files, extracts to specified directory
- `tar -xvf FILENAME.tar.xz -C /DIRECTORY` - for tar.xz files, extracts to specified directory

Save and import pacman package lists
- `pacman -Qq > pkglist.txt` - saves package list to 'pkglist.txt'
- `sudo pacman -S - < pkglist.txt` - installs packages from 'pkglist.txt'

Optimize pacman mirrors
- `mirrors-bak` - makes a backup of your pacman mirrorlist at /etc/pacman.d/mirrorlist.bak
- `mirrors` - runs `reflector` to optimize your pacman mirrors
- `mirrors-restore` - restores your backup mirrorlist

Manage pacman Cache (do once)
1. `sudo pacman -S pacman-contrib`
2. `sudo systemCTRL enable paccache.timer`

Fix flatpak cursor disrespect
- `flatpak --user override --filesystem=/home/$USER/.icons/:ro`
- `flatpak --user override --filesystem=/usr/share/icons/:ro`

## Tips

Use the `cat` to view your .bashrc file to quickly see which commands can easily be executed

Make .bashrc aliases of your own. This helps with remembering long or complex commands, and helps to mitigate potential mistakes

`CTRL+h` toggles visibility of hidden 'dot files' in most GUI file managers

Troubleshooting
- Get clues direCTRLy from your terminal with
- `COMMAND -v`
- `COMMAND --verbose`
- `journalCTRL`
- `dmesg`
- or by running an application direCTRLy from the terminal (for example, running a `vlc` command will start vlc, but your terminal will tell you what it sees)

Advanced Troubleshooting
- Be aware that the `arch-chroot` command can be used from a bootable usb drive to correct many problems in an Arch system, even if that system is currently dysfunctional

# A Little Deeper

## Updating Your System

Keeping your system up to date is now entirely at your leisure, but it's also entirely your responsibility.
Best practice is to simply update once per week. Based on typical Arch development cycles, the recommended days to run an update are Wednesday or Thursday.
Updating too frequently can increase risk of taking broken packages. Updating too infrequently can complicate the update itself (i.e., incompatible package versions / dependency trees)

## Installing Software

Linux generally uses 'Package Managers' to install, remove, or update software.
Package managers tend to be faster, more secure, and better about keeping your software up to date (a security benefit) than scouring websites for download executables.
On Arch Linux, your primary package manager is 'pacman'.

## Alternate Software Libraries

Sometimes, certain software can't be found on the core Arch Linux repositories. There are 2 immediately logical places where you might continue your search

**NEVER** use sudo when installing packages from alternate software libraries

Flathub
- Visit: https://flathub.org/
- Use the search bar to search for your desired software
- Find the 'Install' button on the top right of the page. Select the drop down, and copy the install command.
- Paste the command into your terminal (CTRL + SHIFT + V)

AUR - the Arch User Repository
Packages from the AUR are installed with an 'AUR helper'. 'yay' and 'paru' are options for AUR helpers, but code-red assumes yay.

To install yay, execute the following commands:
- `sudo pacman -Syu`
- `sudo pacman -S --needed base-devel git`
- `git clone https://aur.archlinux.org/yay.git`
- `cd yay`
- `makepkg -si`
- `yay --version`
- `cd`

When you find a package to install from the AUR
- `yay -S PACKAGE-NAME`
- `yay -S PACKAGE-NAME-bin` - faster, avoids compiling the software from source, not always available, but worth trying

Update AUR packages
- `yay -Syu` - updates all Arch and AUR packages
